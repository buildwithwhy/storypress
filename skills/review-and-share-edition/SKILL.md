# Review and share an edition

Read [the edition boundaries](references/edition-boundaries.md) before preparing an export or sharing action.

1. Compare the newspaper with the original testimony and latest corrections. Flag unsupported details and inaccurate quotations for the narrator. Preserve uncertainty.
2. Ask the narrator to approve the current version. Any later edit requires review again. Do not infer approval from generating the draft or saving privately.
3. Identify the requested destination: a private account, a downloadable edition, or a link accessible to anyone who holds it. Explain a link's audience without implying it is restricted to named family members.
4. Prepare the approved snapshot: the newspaper, photo and caption, and selected source details. Exclude interview turns, unfinished text, unselected research, recognition reactions and internal researcher questions.
5. For private saving, verify the authenticated owner and handle revision conflicts. For a web link, verify that the host permits recipients to open it and that online sharing is configured. If it is unavailable, offer the approved downloadable copy instead of inventing a working URL.
6. Perform the requested export or link change only through the app's authorized controls. Do not send messages to recipients or publish publicly unless the user specifically asks for that action.
7. Verify the result. A shared edition remains a snapshot until explicitly updated. Turning off a link prevents later access but cannot recall existing downloaded copies.

This skill guides review and tool use. It is not an additional model call in Storypress: ownership checks, approval gating, snapshot construction and link revocation remain application code.
