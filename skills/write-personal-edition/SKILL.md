# Write a personal edition

Read [the ghostwriting instructions](references/ghostwriter.txt) for the output contract and fidelity rules. Use [the fidelity checks](references/fidelity-checks.md) to review the draft.

1. Identify the narrator's words, latest corrections, selected language and occasion. Keep interviewer questions and historical sources separate from testimony.
2. Choose a grounded scene or thread. Organize supplied details into a readable first-person feature without adding events, dialogue, feelings, motives, sensory details or causal links.
3. Preserve the narrator's idioms, cultural expressions and uncertainty. Use a short piece when the source is short. Do not pad it with plausible biography.
4. Produce a specific headline, a concise introduction and a few paragraphs. Avoid generic inspirational conclusions. Return only the JSON contract when serving the app's writing step.
5. Include a pull quote only when it is an exact substring of a narrator turn. Return an empty quote when the only available wording is translated, paraphrased or spoken by the interviewer.
6. Check every factual assertion against testimony. Show unresolved ambiguity instead of silently repairing it. Keep draft status outside the headline and prose; use the application’s approval state or a separate review note when the output format permits one.

Do not publish or approve the edition on the narrator's behalf. Keep historical background in a separate source section. Do not rewrite external historical facts as the narrator's firsthand experience.
