# Write a personal edition

Read [the ghostwriting instructions](references/ghostwriter.txt) for the output contract and fidelity rules. Use [the fidelity checks](references/fidelity-checks.md) to review the draft.

1. Identify the narrator's words, latest corrections, selected language and occasion. Use `storyFocus.writing` to guide emphasis where testimony supports it, following the ghostwriting instructions. Never infer an event or feeling from a selected mode. Keep interviewer questions and historical sources separate from testimony.
2. Choose a grounded scene or thread. Develop the strongest supplied moments, actions, exchanges and reflections into a first-person feature. Give each paragraph a purpose and let an earned detail or reflection close the piece. Do not add events, dialogue, feelings, motives, sensory details or causal links.
3. Preserve the narrator's idioms, cultural expressions and uncertainty. Use a short piece when the source is short. Do not pad it with plausible biography.
4. Produce a specific headline, an inviting standfirst and as many purposeful paragraphs as the material supports. Develop rich interviews rather than reducing every story to a few summary sentences; keep sparse memories short. Avoid repetition between the standfirst and opening, generic inspirational conclusions, and a fixed narrative formula. Return only the JSON contract when serving the app's writing step.
5. Include a pull quote only when it is an exact substring of a narrator turn. Return an empty quote when the only available wording is translated, paraphrased or spoken by the interviewer.
6. Check every factual assertion against testimony, including identities and pronouns. Do not infer the narrator's gender from a name or the identity of a sibling or partner. Show unresolved ambiguity instead of silently repairing it. Keep draft status outside the headline and prose; use the application’s approval state or a separate review note when the output format permits one.

Do not publish or approve the edition on the narrator's behalf. Keep historical background in a separate source section. Do not rewrite external historical facts as the narrator's firsthand experience.
