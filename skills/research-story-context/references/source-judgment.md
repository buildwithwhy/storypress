# Source judgment

A source can establish a public event, not the narrator's participation in it. Keep recognition optional. For example, a museum page about a 1970s bus model does not establish that the narrator rode that bus.

Use the remembered era to shape the query. Do not set a web publication-date filter to that era: present-day archives may hold relevant earlier records. Identify a retrospective as a retrospective.

Reference: Library of Congress primary-source analysis guidance, consulted October 11, 2026:
https://www.loc.gov/static/programs/teachers/about-this-program/teaching-with-primary-sources-partner-program/documents/critical-thinking.pdf

In Storypress, Nimble supplies retrieved results. The server independently rejects generated URLs absent from those results. That guard does not verify every claim inside a source or eliminate the need for narrator review.
